💼 HR Management System
This is a C# WPF desktop application for managing employees, departments, attendance, leaves, payroll, and more. It includes role-based authentication and supports various administrative features essential for an HR workflow.

✅ Core Features
🔐 User Roles and Authentication
Supports three user roles: Admin, HR Manager, and Employee

Secure login and registration system connected to a SQL Server database

Access control based on roles:

Admin: Full access to all data

HR Manager: Manage employee and leave data

Employee: View personal data, attendance, and payslips

👥 Employee Management
Add, update, delete, and view employee details (name, ID, department, position, salary, contact info)

Search and filter employees by department, position, or name

🏢 Department Management
Manage departments (add, update, delete)

Assign employees to specific departments

⏱ Attendance Tracking
Record check-in and check-out times

Automatically calculate total working hours for each employee

🌴 Leave Management
Employees can apply for leave (sick leave, vacation, etc.)

HR Managers can approve or reject requests

Leave balances tracked per employee

💰 Payroll Management
Calculate salaries based on attendance, leaves, and deductions

Generate monthly payslips

📊 Reporting
Generate reports for attendance, payroll, and employee performance

Export reports to PDF or Excel

🛠 Tech Stack
C# with WPF (Windows Presentation Foundation)

SQL Server for backend database

XAML for UI design
